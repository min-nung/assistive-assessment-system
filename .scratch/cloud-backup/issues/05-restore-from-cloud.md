# 05 — 從雲端取回快照

**What to build:** 治療師在新裝置或重灌後的瀏覽器上登入同一個 Google 帳號，能把先前的個案資料取回。

連結帳號後，若 Drive 上存在快照而本機沒有對應資料，系統提示雲端有可載入的備份，並顯示該快照的**時間與個案數量**，讓治療師確認要載入的是正確的版本。

載入為不可逆的覆蓋操作，因此必須經過明確確認，且**在套用前先自動將本機現有資料匯出成 JSON 檔**作為保險——萬一治療師選錯，仍有退路。

從 Drive 取回的快照視為**不可信輸入**，必須經過與匯入 JSON 檔案完全相同的格式驗證後才能套用。舊版快照需經過既有的資料升級流程，確保欄位結構被正確補齊。

驗證失敗時明確告知原因，並保留本機資料不變——絕不因為雲端資料損毀而清空本機。

**Blocked by:** 04 — 自動上傳快照

**Status:** ready-for-agent

- [ ] 連結帳號後若 Drive 有快照，顯示可載入的提示
- [ ] 提示中顯示快照的時間與個案數量
- [ ] 載入前要求明確確認，並說明本機現有資料將被取代
- [ ] 確認載入前，系統自動匯出一份本機資料的 JSON 檔
- [ ] 載入後個案清單正確顯示雲端快照中的所有個案
- [ ] 載入後各評估模組的資料完整，可正常開啟與繼續編輯
- [ ] 取回的快照經過與手動匯入相同的格式驗證
- [ ] 舊版格式的快照經過資料升級流程後可正常載入
- [ ] 快照格式無效時顯示明確錯誤，且本機資料維持不變
- [ ] 使用者可選擇不載入，繼續使用本機資料
