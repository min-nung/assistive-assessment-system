# 03 — 連結 Google 帳號

**What to build:** 治療師能把系統連結到自己的 Google 帳號，為後續的雲端備份取得授權。

在設定選單中新增「雲端備份」入口。未連結時顯示明確的「未連結」狀態與連結按鈕，讓治療師知道目前資料還沒有雲端保護。點擊後出現 Google 授權畫面，畫面上應清楚顯示系統只要求存取「這個應用程式建立的檔案」。授權完成後狀態立即變為「已連結」。

下次開啟應用程式時不需重新登入——系統靜默取得新的 token。若靜默續期失敗（授權過期、使用者清除 cookie），狀態顯示為「需要重新連結」，但**不以彈窗打斷**正在進行的評估。

治療師也能主動解除連結，供共用裝置情境使用。解除連結只移除本機的授權狀態，**不刪除雲端上既有的快照**——誤觸不應導致備份消失。

這張票只處理授權，尚未上傳任何資料。

**最重要的驗收條件是離線優先不被破壞**：未連結、離線、授權過期等任何狀態下，所有評估功能都必須照常運作。案家經常沒有網路，這是系統的核心價值。

Client ID 為公開資訊，寫入前端設定並附註說明其安全模型（防線是已授權的 JavaScript 來源，而非保密）。Client Secret 絕不進入前端程式碼或版本庫。
